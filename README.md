# Adidas Sales Analysis Dashboard

## 📊 Project Overview

The Adidas Sales Analysis Dashboard is an interactive Power BI project designed to analyze Adidas sales performance and identify key business insights. It provides a clear overview of sales, profit, units sold, profit margin, and product and retailer performance.

## 🎯 Project Objectives

- Analyze total sales and profit performance.
- Track monthly sales trends.
- Compare sales across states and regions.
- Identify top-performing products and retailers.
- Compare sales across different sales methods.

## 🛠️ Tools & Technologies

- Excel
- Power BI
- Data Visualization
- Data Analysis
- Business Intelligence

## 📈 Key Performance Indicators (KPIs)

- **Total Sales:** $899.90M
- **Total Profit:** $332.13M
- **Total Units Sold:** 18M
- **Average Price per Unit:** $45.22
- **Profit Margin:** 42.30%

*Note: KPI values reflect the dashboard snapshot and may change with filters.*

## 📌 Dashboard Features

- Monthly Sales Trend Analysis
- State-Wise Sales Analysis
- Region-Wise Sales Distribution
- Product-Wise Sales Comparison
- Retailer-Wise Sales Performance
- Interactive Year, Month, and Sales Method Filters
- Reset Filters Functionality

## 💡 Key Insights

- The dashboard provides an overview of sales and profitability.
- Monthly trends help identify high- and low-performing periods.
- Regional and state-wise analysis helps compare geographical performance.
- Product and retailer comparisons highlight leading sales contributors.
- Interactive filters allow users to explore performance across different periods and sales channels.
